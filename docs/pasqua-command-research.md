The requested `wcg` command is consistently documented in public WhatsApp bot repositories as **Word Chain Game**. The references include Gifted-Bot-Md and Venocyber-md, both of which list “Word chain Game (wcg)” among their bot games.

Searches for `randompp` did not produce a reliable public command definition. The name is ambiguous: it may mean random profile picture, random password/pin, or a bot-specific feature. It should not be implemented from guesswork. The owner should confirm the intended behavior before this command is added.
